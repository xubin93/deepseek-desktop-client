DeepSeek 桌面客户端（安装版）
========================================

【安装后】
  1. 双击桌面“DeepSeek”启动客户端窗口
  2. 首次使用：打开 设置 → 模型，填入你的 DeepSeek API Key
  3. 右键托盘鲸鱼图标可设置“关闭窗口行为”
     （每次询问 / 后台运行托盘 / 退出并停止）

【目录说明】
  runtime\node    自带的 Node.js 运行时（无需另装）
  packages        已安装的 DeepSeek Harness（npm 包）
  tarballs        离线安装包（安装完成后可删除以省空间）
  home\.dsh       配置与会话数据（API Key、聊天记录）
  app             客户端程序（启动器、托盘、图标）
  postinstall.cmd 安装脚本（安装包运行时执行）
  uninstall.cmd   卸载（开始菜单有快捷方式）

【卸载】
  开始菜单 → DeepSeek → 卸载 DeepSeek
  会停止客户端并删除快捷方式，安装目录可一并删除。

【说明】
  · 外部依赖安装需联网；日常使用也需联网（AI 服务）
  · 所有数据保存在本机安装目录与 home\.dsh 下
